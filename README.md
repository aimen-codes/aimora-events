## AIMORA EVENTS
## Phase 1 - Task 3: Event Booking Platform
AIMORA EVENTS is a modern and responsive event booking platform developed as part of the SQROCK IT Solutions Internship.

## Project Overview
The project provides users with an easy and user-friendly platform to explore upcoming events, view event details, search and filter events, and book tickets or register online.

## Features

- Responsive homepage
- Hero section
- Upcoming event listings
- Event images and posters
- Event name, date and time
- Venue and location information
- Ticket prices
- Event categories
- Event types
- Event details and descriptions
- Organizer details
- Venue details
- Event schedule
- Ticket booking form
- Basic form validation
- Search events by name
- Filter events by category
- Filter events by date
- Filter events by event type
- Mobile responsive navigation
- Responsive design for mobile, tablet and desktop
- Contact information
- Social media links
- Responsive footer
- Modal-based event details and booking
- Smooth page navigation

## Technologies Used
